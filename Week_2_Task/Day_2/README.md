# Implementation Task

# Player Performance Data Visualization
The implementation includes:
1. Creating a Line Chart to visualize the change in average player score over different years.
2. Creating a **Bar Chart** to compare the total scores of the top 10 teams.
3. Creating a **Histogram** to visualize the distribution of average fantasy points among players.
4. Creating a **Boxplot** to analyze the distribution of average scores across the top 8 teams.
5. Creating a **Scatter Plot** to examine the relationship between average disposals and average fantasy points.
6. Creating a **Heatmap** to analyze correlations between different player performance metrics.
7. Using Matplotlib and Seaborn to add titles, axis labels, colors, and other visual improvements to the charts.

* Analyze correlations between different numerical features.
* Create attractive and readable visualizations using Matplotlib and Seaborn.
