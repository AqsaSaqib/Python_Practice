# Data Visualization and EDA

# Project Overview
Exploratory Data Analysis (EDA) of player performance data.
Uses different visualization techniques to understand and analyze the data.

# Conceptual Questions
1) Bar Chart vs Histogram – Understand the difference and use cases.
2) Boxplot – Understand distributions, median, and outliers.
3) Matplotlib Labels – Add titles, axis labels, and legends.

# Visualizations Implemented
1. Line Chart → Average player score over different years.
2. Bar Chart → Total scores of the top 10 teams.
3. Histogram → Distribution of average fantasy points.
5. Scatter Plot → Relationship between disposals and fantasy points.

# Technologies Used
* Python
* Pandas
* Matplotlib

# Learning Outcomes
* Understand different charts used in EDA.
* Learn when to use Bar Charts, Histograms, Scatter Plots.
* Analyze distributions.
* Identify relationships.
* Create clear and attractive visualizations.
